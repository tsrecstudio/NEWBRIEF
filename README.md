# market_scan — срез рынка вакансий hh.ru для ниши «no-code + AI-разработка»

Инструмент + исследование. Отвечает на вопросы: **кого ищут, для чего, что автоматизируют
и сколько за это платят** — чтобы понимать, в какую сторону развивать свои проекты.

**Главный документ — [`REPORT.md`](REPORT.md).** Этот README — про то, как снять свой срез.

---

## Почему здесь нет «одной кнопки спарсить hh.ru»

Публичный API hh.ru закрыт:

- **с 15.12.2025** — соискательская часть API (резюме, отклики, `POST /negotiations`);
- **с апреля 2026** — `GET /vacancies` возвращает `403` для неавторизованных запросов.
  Ключи выдают преимущественно работодателям и рекрутинговым сервисам после модерации.

Источник: [Хабр](https://habr.com/ru/news/1069286/),
[sys-admin.by](https://sys-admin.by/info/it-news/headhunter-zakryl-publichnyi-api-vakansii-chto-izmenitsia-dlia-razrabotchikov-i-analitikov/).

Поэтому сборщиков три, и они честно помечены:

| Команда | Как получает данные | Когда использовать |
|---|---|---|
| `fetch` | официальный API | только если у вас есть токен с dev.hh.ru |
| `html` | страница поиска, которую **вы сами** сохранили из браузера | удобно, не зависит от API |
| `clip` | тексты вакансий, скопированные вручную в файл | самый надёжный, не ломается от вёрстки |

Ни один режим не обходит защиту площадки и не долбит её запросами.

## Быстрый старт

Требования: **Python 3.9+, только стандартная библиотека.** Устанавливать ничего не нужно.

```bash
# 1. Прогон на встроенной выборке реальных вакансий (работает сразу)
python3 -m market_scan demo -o reports/demo_report.md

# 2. Тесты
python3 -m unittest discover -s tests -v

# 3. Анализ своего CSV или JSON
python3 -m market_scan analyze data/my_vacancies.csv -o reports/my.md --json-out reports/my.json
```

## Собрать свои 200+ вакансий вручную

### Способ A — `clip` (рекомендую)

Открываете вакансии на hh.ru, копируете текст в файл. Формат — см. шаблон
[`data/clip_template.txt`](data/clip_template.txt):

```
Заголовок: Интегратор / специалист по автоматизации / no-code
Работодатель: ООО Ромашка
Город: Москва
Опыт: 1–3 года
Занятость: частичная занятость
Зарплата: от 40000 до 120000
Ссылка: https://hh.ru/vacancy/137471009
Текст: Настраивать и дорабатывать CRM-системы под бизнес-процессы клиентов.
Настраивать автоматизации через n8n, Make, Zapier, Albato. Создавать чат-ботов...
=====
Заголовок: AI-инженер (LLM, RAG)
...
```

Разделитель записей — строка из пяти и более `=`. Обязательны только `Заголовок` и `Текст`.

```bash
python3 -m market_scan clip my_vacancies.txt -o reports/my.md
```

На 200 вакансий уходит 1,5–2 часа. Если хочется быстрее — скопируйте только `Заголовок` +
`Текст`, остальные поля опциональны (пострадают только срезы по зарплате и формату).

### Способ B — `html`

1. Откройте поиск на hh.ru, например `https://hh.ru/search/vacancy?text=n8n`.
2. Прокрутите страницу вниз, чтобы подгрузились карточки.
3. `Ctrl+S` → «Веб-страница, только HTML» → сохраните.
4. `python3 -m market_scan html saved.html -o reports/my.md`

Парсер читает состояние приложения из `<script id="__NEXT_DATA__">` — то есть ровно то,
что вы и так видите глазами. Если hh поменяет вёрстку, парсер **не начнёт угадывать**,
а вернёт понятную ошибку и предложит режим `clip`.

### Способ C — `fetch` (если есть токен)

```bash
export HH_TOKEN=...   # приложение на https://dev.hh.ru, модерация пройдена
python3 -m market_scan fetch --query n8n --pages 3 --area 1 -o raw.json
python3 -m market_scan analyze raw.json -o reports/my.md
```

Без `--query` прогоняет 12 запросов, покрывающих нишу (см. `fetch.DEFAULT_QUERIES`):
`n8n`, `автоматизация бизнес-процессов`, `no-code AI`, `разработчик Telegram-ботов`,
`AI-инженер LLM`, `RAG`, `интегратор CRM`, `внедрение нейросетей`, `промпт-инженер`,
`чат-бот разработка`, `ai агент бизнес процессы`, `Make Zapier автоматизация`.

Между страницами пауза 1 с, дубли по ID склеиваются.

## Что считается

`analyze` строит шесть срезов:

1. **Архетипы ролей** — кого ищут. Сначала матчится **заголовок**, и только потом весь текст:
   иначе «AI-инженер», в тексте которого n8n упомянут как один из фреймворков, уезжает
   в «no-code интеграторы».
2. **Бизнес-задачи** — что именно автоматизируют. Главный раздел для продуктовых решений.
3. **Стек** — какие технологии требуют и сколько за них платят.
4. **Что учить под каждый архетип** — топ стека и задач в разрезе ролей.
5. **Формат работы и сигналы в текстах** — удалёнка, ГПХ, «просят портфолио»,
   «поддержка после запуска» (ваш рекуррентный доход), «процент от прибыли» (красный флаг).
6. **Таблица всех вакансий** выборки.

Вилки в EUR/USD приводятся к рублям (`analyzer.FX_TO_RUB` — обновите курсы при необходимости).

## Как расширять таксономию

Все словари — в [`market_scan/taxonomy.py`](market_scan/taxonomy.py), это обычные словари
`название → регулярка`. Правило, по которому они собраны:

> **Если термин встретился в 3+ реальных вакансиях — добавляйте. Иначе таксономия ловит шум.**

Шум — реальная проблема, и она уже всплывала:

- глагол `make` в английском тексте давал ложный Make (Integromat) → теперь ловится только
  рядом с `n8n`/`zapier`/`автоматиз`/`workflow`;
- `оплата` срабатывала на «Оплата обсуждается» и «проектная оплата» → теперь только
  «приём оплаты», «эквайринг», «платёжный шлюз»;
- `max` срабатывал на «max retries» → теперь только рядом с Telegram/бот/мессенджер.

На каждую такую правку в `tests/test_analyzer.py` есть регрессионный тест (класс
`TestRegressions`). **Добавили паттерн — добавьте тест на ложное срабатывание.**

## Проверка

```bash
python3 -m unittest discover -s tests
# Ran 33 tests ... OK
```

Тесты покрывают: парсинг вилок и валют, очистку HTML, попадание паттернов в настоящие
тексты вакансий, определение архетипов по заголовку, бизнес-задачи, агрегацию,
рендер отчёта, оба режима ручного сбора и регрессии на найденные ложные срабатывания.

## Ограничения

- `reports/sample_report.md` построен на **27 карточках** — это демонстрация анализатора,
  а не статистика. Статистика в `REPORT.md` взята из агрегатов на 34 053 / 154 930 / 4 894 вакансии.
- Записи с `source="synthetic"` в CSV восстановлены по дословным формулировкам из
  исследований, а не сняты со страницы вакансии. В отчёте они не выдаются за конкретные вакансии.
- hh.ru закрывает ~60% рынка. Telegram-каналы, карьерные сайты компаний и Хабр Карьера
  в этот инструмент не входят — а для ниши фриланса и ГПХ там может быть больше половины спроса.
