# МСДИС Smart Brief — Интеллектуальный сервис брифования клиентов

Современная контейнеризированная платформа предпроектного брифования клиентов **ООО «МСДИС»** (заказная разработка ПО для автоматизации бизнес- и производственных процессов: MES, WMS, ERP/1С-интеграции, АСУ ТП / OPC UA / Modbus, BPM, высоконагруженные веб- и мобильные системы).

---

## Ключевые возможности

1. **Флагманский ИИ через [CloseRouter API](https://closerouter.dev/)**:
   - По умолчанию в `.env` настроена топовая модель максимального уровня рассуждений и проектирования: **`anthropic/claude-opus-5.5`** с автоматической резервной цепочкой `openai/gpt-6.1-sol → anthropic/claude-sonnet-5.5 → openai/gpt-6-astra`.
2. **Автоматический поиск в сети Интернет (AI Web Research)**:
   - Перед генерацией вопросов ИИ планирует поисковые запросы, сканирует сайт клиента (главную и внутренние страницы `/about`, `/products`, `/services` с защитой от SSRF), ищет отраслевую специфику, стандарты (152-ФЗ, КИИ, Честный ЗНАК, ФГИС и др.) и вероятный ИТ-контур (DuckDuckGo + Wikipedia API + опционально Tavily API).
   - Формирует **ИИ-досье исследования** с кликабельными веб-источниками для архитектора МСДИС.
3. **Вопросы строго по архитектуре в 8 интерактивных форматах**:
   - **«Похоже на вашу ситуацию или нет?» (`like_or_not`)** — быстрые карточки отраслевых гипотез (`✓ В точку` / `◐ Отчасти` / `✕ Не про нас`).
   - **«Что ближе — что дальше?» (`spectrum`)** — биполярная архитектурная шкала компромиссов (1..5).
   - **Мультивыбор с добавлением своих систем (`multi_choice`)** — чекбоксы интеграций + мгновенное добавление своих вариантов.
   - **Сценарии развёртывания и контура ИБ (`single_choice`)** и **Оценка масштаба/нагрузки (`scale_chips`)**.
   - **Матрица приоритетов запуска (`priority_matrix`)** — распределение модулей по корзинам `В 1-й запуск (MVP)` / `Во 2-й этап` / `Не требуется`.
   - **Умные текстовые поля (`short_text` / `long_text`)** с кликабельными чипами-подсказками.
   - **Прикрепление файлов (`file_upload` + универсальная загрузка)** — Drag & Drop таблиц Excel, PDF, DOCX, схем цехов и ТЗ к вопросам.
4. **Ни одного обязательного вопроса и 100% сохранность данных**:
   - Клиент сам выбирает, на что отвечать и в каком порядке (переключение между режимами **«По карточкам»** и **«Все вопросы сразу»** + интерактивная карта разделов).
   - Мгновенное автосохранение каждого клика и символа в SQLite на сервере + локальный офлайн-буфер (`localStorage`) на случай обрыва связи. Можно закрыть вкладку, вернуться через несколько дней или переслать ссылку коллеге (например, ИТ-директору или главному инженеру).
5. **Разграничение прав доступа**:
   - На корневом домене нет публичного списка брифов.
   - Клиент получает доступ **только по криптографически стойкой 192-битной ссылке** `/b/<token>` (+ опциональный **PIN-код доступа**, возможность зафиксировать бриф в режиме чтения или отозвать/перевыпустить ссылку).
   - Защищённый кабинет администратора **`/admin`** со сводкой всех брифов, ответами, скачиванием файлов, экспортом в `.md`/PDF и генерацией **AI Presale Architecture Blueprint**.
6. **Фирменный стиль МСДИС + импорт палитры из PDF**:
   - Из коробки применена фирменная палитра `mcdis.ru` (`#306DFA`, `#486ACC`, `#082A5E`, `#101013`, `#F8F8F9`), а в разделе `/admin → ИИ и Бренд` встроен **автоматический экстрактор векторных цветов из любого корпоративного PDF брендбука**.

## Быстрое развёртывание в контейнере на поддомене МСДИС (за 2 минуты)

### 1. Подготовьте `.env`
```bash
git clone https://github.com/tsrecstudio/NEWBRIEF.git
cd NEWBRIEF
cp .env.example .env
```

Отредактируйте `.env`:
```env
PORT=3000
PUBLIC_BASE_URL=https://brief.mcdis.ru

# Ваш ключ с https://closerouter.dev/keys
CLOSEROUTER_BASE_URL=https://api.closerouter.dev/v1
CLOSEROUTER_API_KEY=closerouter_ВАШ_КЛЮЧ
CLOSEROUTER_MODEL=anthropic/claude-opus-5.5
CLOSEROUTER_FALLBACK_MODELS=openai/gpt-6.1-sol,anthropic/claude-sonnet-5.5,openai/gpt-6-astra

# Учётные данные администратора (/admin)
ADMIN_LOGIN=admin
ADMIN_PASSWORD=СЛОЖНЫЙ_ПАРОЛЬ_МСДИС
SESSION_SECRET=СЛУЧАЙНАЯ_ДЛИННАЯ_СТРОКА_ДЛЯ_ПОДПИСИ_СЕССИЙ
```

### 2. Запустите контейнер через Docker Compose
```bash
docker compose up -d --build
```
- Сервис поднимется на порту `3000` (healthcheck: `GET /api/health`).
- База данных SQLite (`WAL`) и все загруженные клиентами файлы надёжно хранятся в постоянном Docker-томе `msdis_brief_data` (`/app/data`) и сохраняются при любых перезапусках и обновлениях контейнера.

### 3. Пример конфигурации Nginx для поддомена `brief.mcdis.ru`
```nginx
server {
    listen 443 ssl http2;
    server_name brief.mcdis.ru;

    client_max_body_size 30M;

    location / {
        proxy_pass http://127.0.0.1:3000;
        proxy_http_version 1.1;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
        proxy_read_timeout 120s;
    }
}
```

## Локальный запуск без Docker и тестирование

Требуется **Node.js >= 22.5** (используется встроенный нативный движок `node:sqlite`).

```bash
# Установка зависимостей
npm install

# Режим разработки (горячая перезагрузка сервера и клиента на http://0.0.0.0:3000)
npm run dev

# Проверка типов TypeScript
npm run typecheck

# Прогон всех автотестов (безопасность, PIN, SSRF, автосохранение, файлы, ИИ-поиск, PDF-палитра, UI)
npm test

# Продакшн-сборка и запуск
npm run build
npm start
```

## Стек технологий
- **Frontend:** React 19, TypeScript, Vite 6, Tailwind CSS 4, Lucide Icons
- **Backend:** Node.js 22 (ESM), Express, Multer 2, HMAC-SHA256 Session Auth
- **Хранилище:** Нативный `node:sqlite` (WAL-режим) + изолированное файловое хранилище вложений
- **ИИ и веб-поиск:** CloseRouter API (`anthropic/claude-opus-5.5` + fallback) + встроенный мульти-источниковый краулер и веб-поиск
